# electronics-store

**Название проекта:** Интернет-магазин электроники

**Общее описание:** учебный проект по дисциплине «Базы данных». Система предназначена для
учёта продаж аудио-, видео- и бытовой техники: ведение иерархического каталога категорий,
справочников производителей и товаров, прайс-листов, оформление и оплата заказов, учёт
остатков на складах. Серверная часть реализована на Node.js + Express, доступ к базе данных
PostgreSQL выполняется через ORM Sequelize.

**Автор проекта:** ученик группы И-3-25
